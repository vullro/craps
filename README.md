# CRAPS — 홈 화면 설치판

폴더 구성
- index.html — 게임 (효과음 포함, 파일 하나로 동작)
- manifest.webmanifest — 앱 이름·아이콘·전체화면 설정
- sw.js — 오프라인 실행용 서비스 워커
- icons/ — 앱 아이콘

## 1. 인터넷에 올리기 (무료, 5분)
PWA는 https 주소에서만 설치됩니다. 파일을 직접 여는 방식(file://)으로는 설치되지 않아요.

Netlify Drop (가장 쉬움, PC 필요)
1. 이 압축을 풀어 `craps-pwa` 폴더를 만듭니다.
2. PC 브라우저에서 app.netlify.com/drop 에 접속합니다.
3. `craps-pwa` 폴더를 화면에 끌어다 놓습니다.
4. 몇 초 뒤 `https://이름.netlify.app` 주소가 생깁니다.

GitHub Pages
1. 새 저장소를 만들고 폴더 안의 파일을 전부 올립니다.
2. Settings → Pages → Branch를 main으로 저장합니다.
3. `https://아이디.github.io/저장소이름/` 주소가 생깁니다.

## 2. 홈 화면에 설치
- 아이폰(사파리): 주소 열기 → 공유 버튼 → "홈 화면에 추가"
- 안드로이드(크롬): 주소 열기 → 메뉴 ⋮ → "앱 설치" 또는 "홈 화면에 추가"

설치하면 주소창 없이 전체 화면으로 열리고, 한 번 연 뒤에는 인터넷 없이도 플레이됩니다.

## 3. 새 버전으로 바꿀 때
index.html을 교체한 뒤 sw.js 맨 위의 `craps-v1`을 `craps-v2`처럼 올려서 함께 업로드하세요.
그래야 이미 설치한 폰에서도 새 버전을 받아옵니다.

## 저장
잔고·기록·고른 주사위는 그 기기의 브라우저에 저장됩니다.
앱을 지우거나 사파리 데이터를 지우면 기록도 사라집니다.
